# Password Security

Passwords are commonly used to authenticate users and protect accounts.

Weak or reused passwords can increase the risk of unauthorized account
access.

## Strong Passwords

A strong password should be difficult for an attacker to guess.

Good practices include:

- Use long passwords or passphrases.
- Use unique passwords for different accounts.
- Avoid easily guessed personal information.
- Avoid common passwords.
- Use a password manager when appropriate.

## Multi-Factor Authentication

Multi-factor authentication (MFA) adds another authentication factor in
addition to a password.

Depending on the implementation, additional factors can include:

- Something you know
- Something you have
- Something you are

MFA can reduce the impact of a compromised password.

## Password Managers

A password manager can help users generate and store unique passwords
instead of reusing the same password across multiple services.

## Password Attacks

Attackers may use different techniques against passwords, including:

- Password guessing
- Brute-force attacks
- Credential stuffing
- Password spraying
- Phishing

## Password Security Best Practices

1. Use unique passwords.
2. Use long passwords or passphrases.
3. Enable MFA where available.
4. Never share passwords.
5. Avoid using passwords from one service on another service.
6. Change credentials when compromise is suspected.
7. Protect password manager access carefully.

## Conclusion

Good password security reduces the risk of unauthorized account access.
Strong unique passwords combined with MFA provide important layers of
protection.

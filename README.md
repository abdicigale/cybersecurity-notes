# Cybersecurity Notes & Resources

A simple collection of beginner-friendly cybersecurity notes covering
cybersecurity fundamentals, SOC analysis, common cyber attacks, and
password security.

## Project Purpose

The purpose of this project is to create a small cybersecurity knowledge
base while demonstrating a complete Git and GitHub workflow.

This project demonstrates:

- Git repository initialization
- Meaningful commits
- Git branching
- Pull Requests
- GitHub Issues
- Code review
- GitHub Actions
- Remote repository management

## Topics

### 1. Cybersecurity Fundamentals

Basic concepts of cybersecurity, including the CIA Triad and the importance
of protecting information systems.

### 2. SOC Analyst

An introduction to Security Operations Center analysts and their common
responsibilities.

### 3. Common Cyber Attacks

A basic overview of common cyber attacks such as phishing, malware,
brute-force attacks, and denial-of-service attacks.

### 4. Password Security

Basic practices for creating and protecting strong passwords.
